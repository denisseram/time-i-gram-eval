# Rubric E3: cyclic view linked to a linear view

| Req | Met (2) when | Partial (1) if |
|---|---|---|
| R1 | polar layout, week 1 at 12 o'clock, clockwise, one turn per ISO year, value on radius or another channel | week 1 not at top; counter-clockwise; calendar date angle instead of ISO week |
| R2 | one line/ring per ISO year, legend or labels | years indistinguishable |
| R3 | one marker per season at its maximum week, computed from data | per calendar year instead of per season; hard-coded weeks |
| R4 | linear view of 2012-W40…2026-W43 on a date axis | missing years; index axis instead of dates |
| R5 | brushing a range in the linear view highlights the matching weeks in the circle | only a legend/year selection; only static (score 0 for static) |
| R6 | week/month labels around the circle, date axis, value unit | any of the three missing |
| R7 | title + caption that matches the data | caption contradicts data |
